# ✅ 호가 단위(Tick Unit) 검증 구현 완료

## 📌 검증 결과

고객님께서 문의하신 **호가 단위 오류**에 대한 완벽한 검증 및 자동 처리 기능이 구현되어 있습니다.

---

## 🔍 구현 내용

### 1. **호가 단위 규칙 정의** ✅
| 가격 구간 | 호가 단위 | 예시 |
|---------|--------|------|
| 1,000원 미만 | 1원 | 500원, 999원 |
| 1,000 ~ 5,000원 | 5원 | 2,500원, 4,999원 |
| 5,000 ~ 10,000원 | 10원 | 7,500원, 9,999원 |
| 10,000 ~ 50,000원 | 50원 | 25,000원, 49,999원 |
| 50,000 ~ 100,000원 | 100원 | 75,000원, 99,999원 |
| 100,000 ~ 500,000원 | **500원** | **셀트리온(068270)** |
| 500,000원 이상 | 1,000원 | 750,000원 이상 |

### 2. **3가지 검증 함수 구현** ✅

#### `_get_tick_unit(price)` - 호가 단위 반환
```python
tick = KISBroker._get_tick_unit(218_250)
# 결과: 500 (100,000~500,000원 범위 → 500원 호가)
```

#### `_validate_price_tick_unit(price)` - 검증
```python
is_valid, msg = KISBroker._validate_price_tick_unit(218_250)
# is_valid = False
# msg = "호가 단위 오류: 가격 218250원은 호가 단위 500원에 맞지 않습니다. 
#        조정된 가격: 218000원 또는 218500원"
```

#### `_adjust_price_to_tick_unit(price)` - 조정
```python
adjusted = KISBroker._adjust_price_to_tick_unit(218_250)
# 결과: 218,000원 (내림 조정)
```

### 3. **`buy()` / `sell()` 함수 자동 적용** ✅

```python
# 사용자 코드 (호가 단위 신경 쓸 필요 없음)
result = broker.buy(symbol="068270", qty=4, price=218_250)

# 내부 자동 처리:
# [WARNING] [호가 단위] 068270 매수 주문: 호가 단위 오류: 가격 218250원은...
# [INFO] 가격 조정: 068270 매수 218250원 → 218000원 (호가 단위: 500원)
# → 218,000원으로 자동 조정되어 주문 실행
```

## 🎯 사용 방법

### 기본 사용 (자동 처리)
```python
# 호가 단위를 신경 쓰지 않아도 됨
# Broker가 자동으로 검증하고 조정함

result = broker.buy(
    symbol="068270",      # 셀트리온
    qty=4,
    price=218_250,       # ← 호가 단위 위반도 자동 조정
    order_type="00"      # 지정가 주문
)

# 로그:
# [WARNING] [호가 단위] 068270 매수 주문: 호가 단위 오류...
# [INFO] 가격 조정: 068270 매수 218250원 → 218000원...
```

### 명시적 검증 (선택)
```python
# 전략에서 직접 검증하려면:
is_valid, msg = KISBroker._validate_price_tick_unit(price)
if not is_valid:
    # 조정된 가격 사용
    price = KISBroker._adjust_price_to_tick_unit(price)
```

### 호가 단위 확인 (개발 용도)
```python
# 특정 가격의 호가 단위 확인
tick_unit = KISBroker._get_tick_unit(218_250)
print(f"호가 단위: {tick_unit}원")  # 500
```
