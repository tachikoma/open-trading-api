# 호가 단위(Tick Unit) 검증 구현 가이드

## 📋 개요

KIS Broker의 `kis_broker.py`에는 **국내 주식 호가 단위를 자동으로 검증하고 조정**하는 기능이 구현되어 있습니다.

---

## 🔍 호가 단위 규칙 (KRX 기준)

### 가격대별 호가 단위

| 가격 구간                | 호가 단위 |
|----------------------|--------|
| 1,000원 미만           | 1원    |
| 1,000 ~ 5,000원       | 5원    |
| 5,000 ~ 10,000원      | 10원   |
| 10,000 ~ 50,000원     | 50원   |
| 50,000 ~ 100,000원    | 100원  |
| 100,000 ~ 500,000원   | **500원** |
| 500,000원 이상        | 1,000원 |

### 예시: 셀트리온(068270)

**상황**: 셀트리온 가격 218,250원에 4주 주문 시도

- 가격대: 100,000 ~ 500,000원
- 적용 호가 단위: **500원**
- 입력 가격: 218,250원
- 검증: 218,250 ÷ 500 = **정수가 아님** ❌
- **오류 발생**: `모의투자 주문처리가 안되었습니다(호가단위 오류)`

**해결**: 가격을 500원 단위로 조정
- ✅ 218,000원 (조정 후 하한값)
- ✅ 218,500원 (조정 후 상한값)

---

## 🛠️ 구현 함수

### 1. `_get_tick_unit(price, env_mode)` - 호가 단위 반환

```python
tick_unit = KISBroker._get_tick_unit(price=218_250)
# 결과: 500 (100,000 ~ 500,000원 범위이므로)
```

**특징:**
- 정적 메서드 (static method)
- 가격을 입력받아 해당 가격대의 호가 단위 반환
- 모의투자/실전투자 모두 동일 규칙 적용

---

### 2. `_adjust_price_to_tick_unit(price, env_mode)` - 가격 조정

```python
# 218,250원을 호가 단위에 맞게 조정 (내림)
adjusted_price = KISBroker._adjust_price_to_tick_unit(price=218_250)
# 결과: 218,000원
```

**특징:**
- 호가 단위의 배수로 **내림** 조정
- 시장가(0)는 그대로 0으로 반환
- 주문 전 자동 적용됨

---

### 3. `_validate_price_tick_unit(price, env_mode)` - 가격 검증

```python
is_valid, error_msg = KISBroker._validate_price_tick_unit(price=218_250)
# is_valid = False
# error_msg = "호가 단위 오류: 가격 218250원은 호가 단위 500원에 맞지 않습니다. 
#              조정된 가격: 218000원 또는 218500원"
```

**특징:**
- 가격이 호가 단위를 충족하는지 검증
- 시장가(0)는 자동 통과 (검증 대상 외)
- 검증 실패 시 **상세 오류 메시지** 제공

---

## ✅ 주문 함수의 자동 검증

### `buy()` 함수 - 매수 주문

```python
# 내부 동작 (자동):
# 1. 지정가 주문(order_type="00")인지 확인
# 2. 호가 단위 검증 (_validate_price_tick_unit)
# 3. 위반 시 경고 로그 기록
# 4. 가격 자동 조정 (_adjust_price_to_tick_unit)
# 5. 조정 로그 기록
# 6. 주문 실행

result = broker.buy(
    symbol="068270",      # 셀트리온
    qty=4,
    price=218_250,       # ← 호가 단위 위반
    order_type="00"      # 지정가 주문
)

# 로그 출력:
# [WARNING] [호가 단위] 068270 매수 주문: 호가 단위 오류: 가격 218250원은...
# [INFO] 가격 조정: 068270 매수 218250원 → 218000원 (호가 단위: 500원)
```

### `sell()` 함수 - 매도 주문

```python
# buy()와 동일한 로직이 적용됩니다.
result = broker.sell(
    symbol="068270",
    qty=4,
    price=218_250,
    order_type="00"
)

# 자동으로 218,000원으로 조정되어 주문됨
```


## 🎯 주의사항

### 1. 모의투자와 실전투자의 호가 단위

- **동일하게 적용**: 모의투자와 실전투자 모두 KRX 기준 호가 단위 규칙 적용
- 과거: 모의투자는 "100원 단위만" 지원한다고 잘못 알려짐
- **현재**: 정확한 KRX 규칙 적용

### 2. 자동 조정 시 가격 변경

- 사용자가 입력한 가격과 다를 수 있음
- 항상 **내림** 조정 (상향 조정 없음)
- 로그에서 확인 가능 (전략 서버 로그 참고)

### 3. 시장가 주문은 검증 대상이 아님

```python
# 시장가(order_type="01", price=0) → 호가 단위 검증 없음
result = broker.buy(symbol="068270", qty=10, price=0, order_type="01")
```

## 📝 개발 참고사항

### KIS API 요청 파라미터

호가 단위 검증은 다음 KIS API 호출 전에 자동 수행됩니다:

```python
# kis_broker.py 내부에서 자동으로 호출
dsf.order_cash(
    env_dv=self.env_mode,
    ord_dv="buy",  # 또는 "sell"
    pdno=symbol,
    ord_dvsn="00",  # 또는 "01" (지정가/시장가)
    ord_qty=str(qty),
    ord_unpr=str(price),   # ← 호가 단위에 맞는 가격
    # ...
)
```

### 응답 메시지

서버 응답이 200 OK이더라도 body에 오류 메시지가 있을 수 있습니다:

```
모의투자 주문처리가 안되었습니다(호가단위 오류)
```

이 경우:
1. 로그에서 호가 단위 오류 확인
2. 전략에서 가격 검증 추가 (선택)
3. Broker의 자동 조정에 의존 (권장)
